1. Hugging Face storage (required)

Not connected
  • huggingface.co → Settings → Access Tokens → Create new token with write access.
  • GPU Relay creates a private dataset repo for your jobs and checkpoints (default name gpurelay-store).

2. Kaggle GPUs (about 30 free GPU-hours a week)

Not connected
  • Verify your phone number on kaggle.com first: Kaggle gives GPUs only after that.
  • kaggle.com → Settings → API → Create New Token. Paste the token (or the whole kaggle.json).
  • GPU Relay keeps a private Kaggle dataset, gpurelay-secrets, that lets your Kaggle sessions reach your storage.

3. Modal GPUs (optional, $30 free a month)

Not connected
  • modal.com: add a payment method (Modal starts GPUs only then), then Settings → API Tokens → New Token.
  • GPU Relay uses only the free credit unless you raise your paid limit below.

4. Google Colab (optional, you press Run all)

Off
  • In Colab, open the key icon (Secrets), add GPURELAY_HF_TOKEN with your Hugging Face token, and allow notebook access.
  • When a job needs Colab, GPU Relay shows a notebook to open; GPU Relay never drives Colab itself.

5. Limits

  • Paid Modal time a month after the free credit. 0 means GPU Relay never pays (set Modal's own spending limit too).
