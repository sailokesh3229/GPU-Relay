1. Hugging Face storage (required)

Not connected
  • On huggingface.co, open Settings → Access Tokens and create a token with write access. Paste it below.
  • GPU Relay keeps your jobs and checkpoints in a private dataset in your account. The name is gpurelay-store unless you type another one.

2. Kaggle GPUs (about 30 free GPU-hours a week)

Not connected
  • First verify your phone number on kaggle.com. Kaggle only gives GPUs to verified accounts.
  • On kaggle.com, open Settings → API and click Create New Token. Paste the token below (or the whole kaggle.json file).
  • GPU Relay adds a private dataset named gpurelay-secrets to your Kaggle account. Your Kaggle sessions use it to reach your storage.

3. Modal GPUs (optional, $30 free a month)

Not connected
  • On modal.com, add a payment method first. Modal only starts GPUs after that, and you still get $30 of free use each month.
  • Then open Settings → API Tokens, click New Token, and paste the token id and the token secret below.
  • GPU Relay only uses the free $30 unless you raise your paid limit in step 5.

4. Google Colab (optional, you press Run all)

Off
  • In Colab, click the key icon (Secrets) on the left. Add a secret named GPURELAY_HF_TOKEN whose value is your Hugging Face token, and turn on notebook access.
  • When a job needs Colab, your GPU Relay shows an Open in Colab button (and a browser notification, if you allow them). Click it, choose a GPU, and press Run all. GPU Relay never controls Colab itself.
  • If you named your storage repo something other than gpurelay-store, also add a Colab secret GPURELAY_REPO with its full name.

5. Limits

  • How much paid Modal time GPU Relay may use each month after the free $30. 0 means it never pays. Set the same limit in Modal's own settings too.

6. AI auto-fix (optional, uses your own Claude plan)

Not set up

When a job stops with an error in its code, its page offers Fix it with AI. The AI on your own computer reads the code and the error and suggests a change, under your own plan (Claude Pro or Max, or ChatGPT Plus or Pro), so you need no API key. You look at the change and click Apply and rerun. Nothing is sent to the AI until you click, unless you turn on automatic reruns below.

  • On your computer, install Claude Code (how; on Windows: irm https://claude.ai/install.ps1 | iex in PowerShell). Then run claude once and sign in with /login. Claude Code gets no tools at all: it cannot open files or run commands.
  • Optional, with a ChatGPT plan: install Codex (npm install -g @openai/codex) and run codex login. GPU Relay asks it when Claude's fix did not work, or when it has fixed that kind of error more often. Codex runs in its read-only sandbox.
  • Install GPU Relay there too (needs Python 3.10+): pip install "gpurelay @ git+https://github.com/sailokesh3229/GPU-Relay"
  • Make a helper key below and run the command it shows. Keep that window open while you want AI fixes; after the first time, gpurelay helper alone starts it.
