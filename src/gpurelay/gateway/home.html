Finish long ML jobs on free GPUs

GPU Relay checkpoints your training or evaluation script, hands it off before a session or quota limit ends it, and resumes it on another free platform. Results match one uninterrupted run. It uses your own accounts; paid GPU time only within limits you set ($0 by default).

Before you start: what you need

Gather these first. Each token is checked when you add it and stored encrypted; it is never shown again.

  1. A GPU Relay accountrequired
    • Your email and a password of 12 or more characters (and the invite code, if the server asks for one).
  2. Hugging Face: account and a write tokenrequired
    • Sign up at huggingface.co.
    • Settings → Access Tokens → Create new token with write access.
    • GPU Relay creates a private storage repo in your account for your jobs and checkpoints.
  3. Kaggle: account, verified phone, API tokenrequired for automatic free GPUs
    • Sign up at kaggle.com and verify your phone number (Kaggle gives GPUs only after that), about 30 GPU-hours a week.
    • Settings → API → Create New Token, then paste it here.
  4. Modal: account, payment method, API tokenoptional
    • Sign up at modal.com and add a payment method: Modal starts GPUs only then. It includes $30 of free compute a month.
    • Settings → API Tokens → New Token: paste the token id and the secret, and confirm Modal's terms.
    • GPU Relay uses only the free credit unless you raise your paid limit (default $0).
  5. Google Colab: a secret for your notebooksoptional
    • In Colab, open the key icon (Secrets), add GPURELAY_HF_TOKEN with your Hugging Face token, and allow notebook access.
    • When a job needs Colab you get a notice and a notebook: open it in Colab and press Run all. GPU Relay never drives Colab itself.
  6. Your choicesdefaults are fine
    • Colab first or as a fallback, how long to wait for Run all (30 min), and your paid limit ($0).
  7. Your jobrequired
    • A Python script (.py) or notebook (.ipynb), plus requirements.txt if it needs extra packages.
    • Before you submit, GPU Relay checks whether it can resume; most scripts need no changes.

What GPU Relay does for you

Starts sessions on Kaggle and Modal through their official APIs (always private), checkpoints at safe points, hands off before limits, notifies you when a job needs you on Colab or finishes, and keeps your outputs. Your code runs only on your own platform accounts, never on this server.
